# Учёт расходов в поездке

Программа считает общие и средние расходы по списку поездки и печатает отчёт.

## Запуск

В PowerShell из папки `trip`:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python trip.py
```

Отчёт показывает количество записей, общую сумму расходов и среднюю трату.
Расчёты находятся в `calculator.py`, форматирование отчёта и запуск — в `trip.py`.

Ожидаемый вывод:

```text
ОТЧЁТ ПО ПОЕЗДКЕ
--------------------------------
записей: 10
всего потрачено: 7900 ₽
средняя трата: 790.00 ₽
```
